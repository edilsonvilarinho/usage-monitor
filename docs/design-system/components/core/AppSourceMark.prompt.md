Identifies the integration a surface belongs to — a 2px stroke, not a colored card.

```jsx
<AppPanelHeader mark={<AppSourceMark source="codex" />} title="Codex" />
<AppSourceDot source="deepseek" /> DeepSeek
```

The seven accents are fixed (AA on both surfaces, >=20 degrees apart). `opencode` is the color of the monitored integration — it is never the app's brand color. `openrouter` does not reuse any other accent: OpenRouter is not the vendor of any other monitored source.
