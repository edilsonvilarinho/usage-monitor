Identifies the integration a surface belongs to — a 2px stroke, not a colored card.

```jsx
<AppPanelHeader mark={<AppSourceMark source="codex" />} title="Codex" />
<AppSourceDot source="deepseek" /> DeepSeek
```

The six accents are fixed (AA on both surfaces, >=20 degrees apart). `opencode` is the color of the monitored integration — it is never the app's brand color.
